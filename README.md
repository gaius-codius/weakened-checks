# weakened-checks

Reports changes that weaken or bypass a check (a silenced lint, a skipped or
deleted test, a loosened bound, a changed check config), so each one is
explained in the pull request or, where a project forbids it, refused.

Work in progress: the detector, its GitHub action and its documentation land
through pull requests before the first release.
